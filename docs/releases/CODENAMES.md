## Правила

- Codename — 1–3 слова на **английском**, образные и **уникальные** (проверить эту таблицу перед тегом).
- Запрещены generic-префиксы: Quick, Update, Patch, Fix, Release.
- Один codename на волну релизов (1.0.x); для 1.1, 1.2 — новое имя обязательно.
- Перед `git tag` добавить строку сюда и в заголовок секции [CHANGELOG.md](./CHANGELOG.md).
