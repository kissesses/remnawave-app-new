add_link Подключение панели

Укажите базовый URL Remnawave, API token и опционально Squad UUID. После добавления настройте URL панели, тарифы и видимость в боте.

category Тарифы

Каждый хост имеет свой набор тарифов: месяцы, цена, лимит трафика (GB), HWID. Стиль кнопки и emoji ID задаются отдельно для хоста и тарифа.

devices Режим устройств

По тарифу — лимит HWID из тарифа. Выбор (tiers) — пользователь докупает устройства по tier-ценам; базовое количество задаётся отдельно.

terminal SSH и Speedtest

SSH на хосте используется для автоустановки Speedtest CLI. SSH-цели — отдельные серверы для мониторинга без привязки к Remnawave-панели. Управление на странице Ноды.

visibility Видимость

Скрытые хосты не показываются пользователям в боте, но остаются в админке. Порядок хостов меняется перетаскиванием в списке слева.
