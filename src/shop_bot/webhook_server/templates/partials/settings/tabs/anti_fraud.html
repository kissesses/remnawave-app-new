mail_lock Блоклист email при регистрации

Проверка срабатывает при POST /api/auth/email/register в WebApp. Встроено {{ af.builtin_domains or 0 }} disposable-доменов; дополните списки ниже.

info Ограничения

Anti-Fraud не заменяет ручную модерацию и не банит пользователей. Блоклист email действует только на регистрацию через WebApp. Для доступа к разделу нужно право settings_anti_fraud (или settings_access для просмотра).
